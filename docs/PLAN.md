# 트래블핀 기획 메모

목표 기한 2일, 일반 사용자 대상 웹서비스.

## 확정된 것

| 항목 | 결정 |
| --- | --- |
| 서비스명 | 트래블핀 (TravelPin) — 변경 가능성 열어둠 |
| 뽑기 범위 | 국내(대한민국)만. 해외 확장 미정 |
| 데이터 단위 | 시/군/구. 섬이 더 큰 시·구의 일부면 분리, 섬이 곧 시·군이면 통합(예: 거제도=거제시) |
| 지도 | 외부 지도 API 없이 자체 SVG. 이유: 요금/쿼터 회피 + 디자인 자유도 |
| 결과 연동 | `https://map.naver.com/p/search/{지역명}` 딥링크 새 탭. API 키 불필요 |
| 페이지 구조 | 원페이지 (랜딩·뽑기·결과가 한 화면) |
| 다시 뽑기 | 무제한 |
| 공유 | Web Share API, 미지원 시 클립보드 복사 |
| 거리 필터 | 현재 지역 직접 입력(자동완성) → 최대 이동 거리 슬라이더 50~400km, 50km 단위 |
| 섬 추가 | 토글 ON/OFF. 기본 OFF. ON이면 배로 가야 하는 관광섬이 거리 무관하게 후보에 추가 |
| 기술 스택 | HTML/CSS/JS, 프레임워크 없음 |
| 배포 | Vercel (미진행) |

슬라이더 상한 400km는 운전 가능한 육지 기준 국토 최대거리 약 500km에서 -100km로 잡은 값.

## 디자인

다크 테마(남색 배경 `#12131c` + 보라 포인트 `#8b7cf6`), 좌측 컨트롤 패널 + 우측 결과/미니맵 레이아웃.
사용자가 업로드한 시안을 그대로 구현한 상태.

> 논의 중 미니멀/빈티지/컬러풀/귀여운 톤 초안을 비교했으나 최종적으로 다크 테마 시안으로 진행.
> **최종 확정 여부는 재확인 필요.**

## 데이터 현황

- `mainPool` 225곳 — 거리 기반 뽑기 대상
- `islandPool` 4곳 — 제주시, 서귀포시, 울릉군, 인천 옹진군
- 좌표는 시청/군청 소재지 기준 근사값 (공개 좌표 데이터셋 기반)
- 이름 중복은 `고성군(강원)` / `고성군(경남)`으로 구분
- 신안군(홍도·흑산도 등)은 이번 버전에서 신안군청 소재지 기준으로 일반 풀에 포함
